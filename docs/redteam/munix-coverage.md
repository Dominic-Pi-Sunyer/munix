2. ~~**Cross-region quarantine poisoning (Item 14):**~~ Done Oct 27 (`quarantine_trust.rs`).

4. **Influence between two allowed clean destinations (Item 2):** Write a test in `crates/munix-supervisor/src/reviewer.rs` with two store contacts (`store.contacts.boss` and `store.contacts.vendor`) both allowed by the step policy, where a poisoned review steers the agent to the wrong contact and the reviewer must deny it against the prompt.
5. **Spin budget reset on repeated read calls (Item 13):** Write a test in `crates/munix-runtime/tests/watchdog.rs` where an agent alternates model calls with repeated read-only tool calls on the same step, and verify that `SpinBudget` trips when no new plan step advances.
